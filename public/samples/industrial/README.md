# Industrial kit

Eight original procedural drum sounds generated by
`scripts/generate-industrial.mjs`. No recordings or third-party audio are used.
The existing Salamander acoustic kit retains its own attribution and license.

The generated Industrial WAV files are dedicated to the public domain under
CC0 1.0 Universal (SPDX: CC0-1.0):
https://creativecommons.org/publicdomain/zero/1.0/
You may copy, modify and redistribute them, including commercially, without
attribution. They are provided without warranty.

Run `npm run samples:industrial` using Node.js 24 to regenerate the committed
assets. Builds do not generate or download audio. Output is mono 48 kHz,
16-bit PCM, normalized to a peak of 0.8. Each sound has deterministic seeded
noise, an exponential decay, a 0.5 ms attack and a 15 ms end fade.
The manifest records each seed, base frequency, frame count and SHA-256.

Kick and toms use saturated descending sine sweeps with a noise transient.
Snare combines noise, a pitched body and inharmonic partials. Hats and cymbals
combine high-pass noise and inharmonic partials with different decay lengths.
These sounds are an original Industrial palette, not emulations of a named
commercial drum machine.
