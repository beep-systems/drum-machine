# Работа с Drum Machine

Браузерная драм-машина для занятий на гитаре: рок, хард-рок и метал. Интерфейс и документация — на русском. Основные браузеры — настольные Chrome и Edge. Сервер раздаёт статику; звук формируется на клиенте.

## Архитектура

- `src/model.ts`: типы, восемь инструментов, два такта 4/4, 32 шага и пресеты.
- `src/audio/`: независимый от React движок, расчёт времени, рендер дорожек.
- `src/storage.ts`: версионированное состояние, проверка импорта, экспорт.
- `src/App.tsx`, `src/styles.css`: интерфейс и доступность.
- `public/samples/`: Salamander, атрибуция, лицензия и manifest. Сборка не скачивает сэмплы.
- Docker: Node.js 24 → Nginx на 8080; Compose публикует `${PORT:-8080}`.

## Команды

Node.js 24, npm, зафиксированный `package-lock.json`.

```sh
npm ci
npm run dev
npm run typecheck
npm run lint
npm test
npm run build
npm run test:e2e
```

Браузерные тесты: `npx playwright install chromium`. Можно использовать установленный Chrome через `PLAYWRIGHT_CHANNEL=chrome` (PowerShell: `$env:PLAYWRIGHT_CHANNEL='chrome'`). Тесты запускают Vite самостоятельно. В ограниченном окружении используйте `--cache .cache/npm`.

## Правила

- Строгий TypeScript. Расчёты и валидация отделены от DOM и Web Audio.
- Момент удара задают аудиочасы; таймеры JavaScript и requestAnimationFrame не управляют отдельными ударами. Анимация только отображает позицию.
- BPM не меняет высоту сэмплов. Новый рисунок включается на границе цикла. Громкость и mute применяются сразу с коротким сглаживанием.
- Асинхронный запуск/рендер проверяет актуальность перед включением звука. Stop отменяет загрузочный запуск, отсчёт и будущие источники. Ошибки не запускают автоповтор.
- Сохранять хвосты на стыке циклов и заглушение открытого хэта закрытым, включая переход конца рисунка к началу.
- Проверять JSON и localStorage. Ошибочный импорт не меняет библиотеку; повреждённое сохранение не перезаписывать автоматически.
- Не добавлять внешние CDN, шрифты или сетевые зависимости для занятий. Приложение должно работать по HTTP в домашней сети без обязательных secure-context API.
- Для аудиофайлов фиксировать источник, лицензию и обработку. Не заменять акустические записи синтезом без запроса пользователя.
- Запускать соответствующие проверки; для аудио — гонки start/stop/update и Web Audio в браузере. Не заявлять о прослушивании или Docker-проверке, если они не выполнены.
- Сохранять пользовательские изменения. Не публиковать приложение и не настраивать домашний сервер без отдельного запроса.
