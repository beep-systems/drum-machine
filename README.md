# Drum Machine

Акустические ударные для занятий на гитаре. Выбери рок- или метал-ритм, установи темп и играй через комбик. Ударные звучат через **основное устройство вывода компьютера, на котором открыт браузер**. Домашний сервер только раздаёт приложение.

## Запуск в Docker

На домашнем сервере с Docker и Compose:

```sh
docker compose up -d --build
```

Открой `http://<адрес-сервера>:8080` и нажми **Играть**. Браузеру требуется пользовательское действие для запуска звука. Сэмплы уже включены в репозиторий; установка Node.js на сервер вне Docker не нужна.

Другой порт задаётся переменной `PORT`, например в `.env` рядом с Compose:

```dotenv
PORT=8090
```

```sh
docker compose up -d --build   # запуск / обновление
docker compose logs -f        # логи
docker compose down           # остановка
```

Сборка Node.js 24 → Nginx, проверка `/healthz`, автоматический перезапуск. База данных, аудиоустройства сервера и постоянные тома не нужны. Приложение размещается в корне сайта. Если используется обратный прокси, направь отдельный хост на порт контейнера 8080; HTTPS настраивается на прокси.

## Управление

- **Пресеты:** базовый рок, хард-рок, half-time, двойная бочка, thrash и blast beat. Выбор загружает рисунок и исходный BPM, сохраняя громкость.
- **Темп:** 40–300 BPM, поле, кнопки ± или ползунок. Два такта 4/4, 32 шага шестнадцатыми.
- **Играть / Стоп:** кнопка или пробел вне полей и кнопок. Повторный старт начинает с начала. Отключаемый отсчёт — четыре клика перед стартом.
- **Сетка:** клик включает/выключает удар; Shift+клик включает/снимает акцент. Стрелки перемещают фокус между клетками, пробел нажимает клетку, Shift+Enter меняет акцент.
- **Микшер:** громкость и выключение каждой дорожки. Нажми имя инструмента для прослушивания. Бочка, малый барабан, закрытый и открытый хэты, крэш, райд и два тома.
- **Во время игры:** сетка и BPM меняются на ближайшей границе двухтактового цикла после подготовки аудио. Индикатор показывает ожидающее изменение. Громкость и mute действуют сразу. BPM не меняет высоту ударных.
- **Очистить сетку:** создаёт пустой текущий рисунок, сохраняя библиотеку.

По умолчанию: базовый рок, 100 BPM, громкость 65%, отсчёт включён. Ритм продолжает играть при обычном переключении вкладок. Сон компьютера, выгрузка страницы или приостановка аудио браузером прерывают звук; для возобновления нажми «Играть».

## Сохранение и перенос

Текущий рисунок, BPM, микшер и библиотека сохраняются в localStorage этого браузера. После перезагрузки звук не запускается сам. Дай ритму имя и нажми **Сохранить ритм**. Удаление из библиотеки не стирает текущую сетку.

**Экспорт** выгружает сохранённую библиотеку JSON; текущий рисунок сначала нужно сохранить. **Импорт** добавляет записи, пропускает одинаковые рисунки с тем же именем и BPM и не перезаписывает локальные ритмы. Лимиты: 128 записей, имя до 60 символов, файл до 1 МБ. Неверный JSON или неизвестная версия не меняют библиотеку.

На другом устройстве, в другом браузере или по другому адресу/порту будет отдельное хранилище. Для переноса используй экспорт. При недоступном хранилище приложение предупреждает и работает в памяти. Повреждённое сохранение остаётся нетронутым, автосохранение отключается; экспортируй нужные ритмы перед очисткой данных сайта.

## Аудиовыход

Используется основной аудиовыход браузера/ОС. В Windows выбери колонки или аудиоинтерфейс в **Параметры → Система → Звук**, при необходимости — устройство для браузера в микшере громкости. Если браузер не подхватил смену устройства, останови звук и перезагрузи страницу.

Приложение не запрашивает микрофон, не записывает гитару и не передаёт звук на сервер. Гитара и комбик работают отдельно.

## Разработка и проверки

Требуются Node.js 24 и npm.

```sh
npm ci
npm run dev
```

Vite выведет адрес (по умолчанию `http://localhost:5173`). Проверки и production-сборка:

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run preview
```

Браузерные тесты:

```sh
npx playwright install chromium
npm run test:e2e
```

Или установленный Chrome: `PLAYWRIGHT_CHANNEL=chrome npm run test:e2e` (PowerShell: `$env:PLAYWRIGHT_CHANNEL='chrome'; npm run test:e2e`). Для Edge — `msedge`. В ограниченном окружении npm может потребоваться `--cache .cache/npm`.

React и TypeScript отвечают за интерфейс, Web Audio — за звук. Дорожки предварительно собираются через OfflineAudioContext и синхронно зацикливаются с учётом затуханий. Смена ритма планируется по аудиочасам; частота отрисовки не определяет момент удара.

Основные модули: `src/model.ts`, `src/storage.ts`, `src/audio/`, `src/App.tsx`. Правила разработки: [AGENTS.md](AGENTS.md). Тесты проверяют время, валидацию, отмену асинхронного запуска и браузерные сценарии.

## Сэмплы и границы версии

Локальная выборка [Salamander Drumkit](https://github.com/endolith/Salamander-Drumkit), автор **Alexander Holm**, лицензия **CC BY-SA 3.0**. Атрибуция, обработка, лицензия и контрольные суммы: [public/samples/](public/samples/README.md). Во время занятий внешних запросов нет. Повторная подготовка: `npm run samples:prepare` (оригинальный архив ~370 МиБ, нужен `tar` с bzip2).

Основные браузеры — настольные Chrome и Edge; на телефоне сетка прокручивается горизонтально. Пока нет сложных размеров, MIDI, записи гитары, серверной синхронизации и автоматических сбивок. Контейнер подготовлен для самостоятельного развёртывания; домашний сервер и публичный доступ настраиваются отдельно.
